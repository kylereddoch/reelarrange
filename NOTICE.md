# Notices

## TMDB

Reelarrange uses the TMDB API to search for movies and television shows and to retrieve episode titles.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB API access is subject to TMDB's own terms and policies. Users provide their own API Read Access Token or v3 API key.

## Jellyfin

Reelarrange produces file and folder layouts intended to interoperate with Jellyfin.

Reelarrange is an independent project. It is not affiliated with, sponsored by, or endorsed by the Jellyfin project. Jellyfin names and documentation links are used only to describe compatibility.

## Third-party media

Reelarrange does not download media, bypass access controls, or provide torrent functionality. Users are responsible for ensuring they have the right to copy, move, rename, and use the files they select.
