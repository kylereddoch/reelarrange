# Support

Reelarrange is a community project. GitHub Issues are the primary support channel once the repository is published.

## Good bug reports include

- Reelarrange version.
- Windows version.
- Copy or Move mode.
- Collision policy.
- A sanitized source tree and expected destination tree.
- The exact error text.
- Relevant lines from `%LOCALAPPDATA%\Reelarrange\activity.log` with private paths redacted.

## Before posting

- Never share a TMDB token or API key.
- Redact usernames, NAS hostnames, IP addresses, and private share names.
- Do not upload copyrighted media samples.
- Confirm whether a transfer is still running by checking the transfer-status window.
- Remember that a cross-drive move copies the file before deleting the source and can take several minutes.

## Not supported

- Downloading media or configuring torrent clients.
- Jellyfin server administration.
- Bypassing DRM or access controls.
- Recovering files deleted or replaced outside Reelarrange.
